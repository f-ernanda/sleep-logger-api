Append a new entry to `docs/decisions.md`, using the template already at the top of that file
(Context / Decision / Consequences), with today's date and title "$ARGUMENTS".

Base the Context/Decision/Consequences on what's already been discussed in this conversation —
don't invent rationale that wasn't actually given. If any of the three sections isn't clear from
context, ask before writing it.

Never edit or renumber existing entries in the file; only append. If this decision reverses an
earlier one, say so explicitly in the new entry rather than editing the old one.
